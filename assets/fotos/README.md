# Fotos del local

Suelta aquí los ficheros con estos nombres exactos (vale .jpg .jpeg .png .webp .avif):

- `01-vitrina-tartas`   — vitrina de tartas y pastas
- `02-vitrina-bolleria` — vitrina de bizcochos y bollería
- `03-rincon`           — el rincón del espejo
- `04-barra`            — la barra

Luego `python3 build.py`. No hace falta recortarlas: el encuadre se ajusta con `--pos`
en `FOTOS_LOCAL` (build.py) y el realce con `--photo-filter` (styles.css).
